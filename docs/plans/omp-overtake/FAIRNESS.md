# Competitive evaluation fairness

Paired runs use explicit preinstalled binaries, the same provider/model/effort where possible, fresh isolated homes and workspaces, equal deadlines and cost ceilings, randomized agent order, and at least three repetitions for live campaigns. Cross-run memory and telemetry are disabled. Failures and timeouts count in reliability. Fixture or verifier changes invalidate prior results.

No runner may download a competitor, expose host credentials in artifacts, or silently weaken an unsupported task.
